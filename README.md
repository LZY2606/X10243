# 滴定热谱审议（ITC 注射积分 / 稀释热 / 绑定模型）

面向生物物理实验室的本地 ITC（等温滴定量热）审阅应用：导入原始功率曲线、
注射时序和空白对照，逐注射审阅积分、稀释热扣除与绑定模型候选。
Python + FastAPI + NumPy + SQLite + 服务端 SVG，无账号、无云服务。

## 安装与运行

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m pytest -q
.venv/bin/uvicorn app:app --host 127.0.0.1 --port 5354
```

打开 http://127.0.0.1:5354 即进入已装载离线案例包的审阅页。

## 分层原则（不可变材料 vs 可修改决定）

- 不可变材料（分槽版本化）：功率采样 power、注射时序 injections、样品
  浓度 concentrations、温度 temperature、池体积 cell_volume、基线 baseline、
  空白对照 blank（空白功率曲线与其注射时序作为一个材料槽整体版本化）。
  导入时保留原始表示，派生层才规范化；无法转换的值留在原位置并附诊断。
- 可修改决定：首注舍弃、单注舍弃、积分端点、空白对应规则、策略参数
  （如等优模型 delta-BIC 阈值）、模型接受或拒绝、人工覆盖。决定只追加、可冲突。
- 派生结果（内容寻址 DAG）：积分窗、原始热量、空白对应与稀释热、
  归一化热、绑定模型拟合。每个节点记录输入摘要、规则/参数版本与父级依赖。
  浓度修订只使模型等下游节点过期，不改写原始积分。
- 事件溯源：所有输入片段、判定状态、受影响对象与人工决定均为机器可读事件；
  旧事件处恢复的是当时的依赖版本与可见结论，绝不用最新结果覆盖历史。

## 关键业务规则（服务端可测，位于 itc/core）

- 注射后峰允许重叠：积分窗按相邻注射时刻自动收缩为不重叠分区，不重复计数，
  并显式标记 overlap；积分窗绝不跨越数据缺口，否则置 blocked:gap。
- 首注舍弃为决定，原始积分仍保留但不参与稀释归一与拟合。
- 空白对照按声明的规则对应（按注射序号 / 按体积最近），每条扣除记录规则版本；
  空白对应缺失时保留原始热量并标记 blank_missing，不以零冒充扣除。
- 绑定候选：一位点（Wiseman）、两位点、纯稀释（常数热）。无法唯一决定时，
  delta-BIC 容差内的全部合法候选都保留为等优集合，顺序对等价输入稳定。
- resource_budget_exhausted、format_corrupt、semantic_unsolvable
  是三种不同结果。

## 离线案例包

itc/cases/titration_heats_case.json 与 itc/cases/build_case.py 构成专门领域案例
（非通用表格）。主叙事包含初始完整导入（七槽分开版本化）、一次浓度修订、
一次只影响局部依赖的基线源数据改动；分支实际经过重叠注射峰、首注舍弃、
空白对应缺失、浓度修订、多个等优模型、数据缺口与积分端点；另有人工决定互相
冲突的第二意见分支。每个操作是可重放事件，最终状态可反查材料版本、规则版本与
决定。

## 测试

tests 覆盖七类边界情形、导出/导入往返（身份、顺序、来源关系）、半写恢复、
三态错误与案例包重放。业务逻辑位于 itc/core 与 itc/storage，可被直接调用。
